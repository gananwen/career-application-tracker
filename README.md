# Career Application Tracker

A full-stack web application that helps students and job seekers manage job applications, interviews, offers, and follow-ups in one centralized dashboard.

## 🚀 Features
- Secure authentication using JWT
- Application tracking with CRUD operations
- Smart dashboard with analytics and charts
- Kanban board and calendar view
- Interview practice simulator
- ATS keyword analyzer
- Offer comparison tool

## 🛠 Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MySQL
- Tools: VS Code, GitHub
